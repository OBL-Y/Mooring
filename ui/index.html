Mooring needs Accessibility access to move windows.

Open System Settings › Privacy & Security › Accessibility and turn on Mooring.

Export diagnostics Saves a zip of the logs and saved layouts to Downloads, to attach to a bug report. It includes window titles, so check it before sharing.

Saved Layouts

Mooring saves a layout for each display setup and keeps it up to date. Lock a layout to stop it changing.
